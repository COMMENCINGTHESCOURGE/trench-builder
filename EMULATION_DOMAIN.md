# An emulator is a digital twin of hardware.
# It mimics another system's hardware/software so programs
# designed for that system can run elsewhere.

# TRENCH BUILDER is an emulator of physical reality.
# It mimics light transport, material response, thermal behavior,
# and electromagnetic fields so designs can be tested virtually.

# SAME CONCEPT, DIFFERENT SCALE:
#   Game emulator:    mimics console hardware → runs games
#   TRENCH BUILDER:   mimics physics → runs simulations
#   Digital twin:     mimics building → runs predictions
#   Hyperframes:      mimics video editor → renders content
